# Architecture decision records

Short records of the decisions that shaped the project, with the alternatives considered.

| #                                              | Decision                                                       |
| ---------------------------------------------- | -------------------------------------------------------------- |
| [0001](0001-pwa-first.md)                      | PWA first, native Android later                                |
| [0002](0002-d1-for-metadata.md)                | D1 for metadata instead of a `library.json` in R2              |
| [0003](0003-single-owner-auth.md)              | Single-owner device pairing instead of accounts or an open API |
| [0004](0004-opus-remux.md)                     | Ogg Opus, remuxed from YouTube by default                      |
| [0005](0005-offline-audio-in-cache-storage.md) | Offline audio in Cache Storage, played through blob: URLs      |
