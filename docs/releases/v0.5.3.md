**Carpetas, portadas de playlist y juntar playlists.**

- Nuevas **carpetas** para ordenar tus playlists. Se crean desde la lista de playlists. Si borras una carpeta, sus playlists no se borran: vuelven a la lista.
- Cada playlist puede tener su **portada**: por defecto un mosaico con las portadas de sus canciones, o una foto que elijas tú.
- Nuevo **Juntar con…** en el menú «…» de una playlist: junta dos playlists sin repetir canciones. Puedes elegir si se borra la otra.
- Puedes **arrastrar** una playlist a una carpeta, o sobre otra playlist para juntarlas. Se arrastra desde el asa ⠿, así la lista sigue deslizándose con el dedo.
- La copia entre almacenamientos también lleva las carpetas y las portadas.
- El **temporizador de apagado** tiene ahora un botón claro «Quitar temporizador». El enlace amarillo queda solo para cambiar el tiempo.
- Si tu Cloudflare es de una versión antigua, la app te avisa de que todavía no admite carpetas ni portadas. Tu música y tus playlists siguen bien.
