**Descarga música de YouTube desde la app.**

- Nueva pestaña **Descargar**: busca canciones, vídeos o playlists (o pega un enlace de YouTube / YouTube Music) y descárgalos con un toque. Las playlists se pueden crear también en tu biblioteca.
- Las descargas siguen aunque salgas de la app, con el progreso en una notificación, y continúan solas si cierras la app a medias.
- El descargador se actualiza solo cada semana (o desde el botón «Actualizar»), así que no hace falta una versión nueva de la app cuando YouTube cambia algo.
- Con tu Cloudflare: las canciones se suben allí (y opcionalmente se guarda una copia en el móvil) y, desde el ordenador, puedes **enviar canciones al móvil** para que las descargue.
- Al importar archivos se leen el título, el artista, el álbum y la carátula que lleven dentro.
- «Sin conexión» está ahora en Ajustes → Música sin conexión.

**Qué archivo descargar:** `aske-stream-0.3.0.apk` sirve para casi todos los móviles. `aske-stream-0.3.0-armv7.apk` es solo para móviles antiguos de 32 bits. Si ya tienes la app, se actualiza sola desde Ajustes → Aplicación.
