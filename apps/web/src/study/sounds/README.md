# Ambient sound files

Study mode generates white, gray and brown noise in code. Rain and waves need real recordings,
which are bundled here as `rain.ogg` and `waves.ogg`. If a file is missing, that sound is simply
not offered.

## Requirements

- License: CC0 (public domain). Nothing that needs attribution.
- Format: Opus in an Ogg container, mono, 48 kbps.
- Length: 60-120 seconds, edited so it loops without an audible cut.
- Size: at most 600 KB each.

## Recommended sources

- Freesound, with the license filter set to CC0.
- BigSoundBank.
- OpenGameArt, with the license filter set to CC0.
